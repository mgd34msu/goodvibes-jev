# Browser judgment runtime captures

`runtime.json` is generated by
`products/daemon/src/test/runtime/browser-judgment-http-capture.test.ts` against the
actual daemon runtime composition and authenticated loopback HTTP server. The
configured System One endpoint is an owned synthetic server. Its probabilities,
usage and reported model label are test inputs, not evidence of live model quality
or provider access. No live credentials are used or recorded.

Regenerate from the repository root:

```sh
GOODVIBES_TEST_BROWSER_JUDGMENT_FIXTURE_DIR="$PWD/products/webui/e2e/support/fixtures/browser-judgment-runtime" \
  bun packages/engine/scripts/test.ts --cwd ../../products/daemon \
  src/test/runtime/browser-judgment-http-capture.test.ts
```

The fixture preserves each exact `Response.text()` string, the request input and
HTTP status. Palette runs resolve all 27 real built-in descriptors and a companion
chat created through the real daemon. The real runtime records every decision and
returns the readings/evidence consumed by the browser. Replay rejects differences
in query, source reference, candidate identities or order. Only the top-level
request correlation UUID is re-echoed to the browser; the remaining response
bytes, including readings and evidence, are preserved.

The unknown close failure is deliberately produced by a synthetic handler on the
canonical `companion.chat.sessions.close` descriptor via the real generic invoke
HTTP route. The real router issues its owner-bound error reference, and the real
daemon-refusal battery resolves it. Browser replay serves this same-method failure
on the direct companion close URL used by App. This is a documented route replay,
not a claim that the direct close handler generated the captured unknown failure.
Successful DELETE and subsequent empty LIST are separately captured real writes
against the owned fixture chat, after a real direct close. Unrelated shell traffic
uses the existing mock daemon.

The missing-reference browser case intentionally removes only `errorRef` from the
captured failure as an adversarial mutation; it is not described as an unmodified
runtime wire. Held readings are genuine runtime outputs. Delayed responses are
released after query edits, palette dismissal, or real cross-tab sign-out to prove
that old evidence cannot cause navigation or continuation of the delete chain.
